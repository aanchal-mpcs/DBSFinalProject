# UChiSchedule v4 Updates

## update1_2026-05-16

This update summarizes the product and UX work completed this week on the extension itself.

### Theme controls and dark mode

- Added a real extension-wide theme preference instead of relying only on system detection.
- The extension now supports:
  - `System`
  - `Dark`
  - `Light`
- Added a manual theme toggle to both main extension surfaces:
  - the popup
  - the full calendar page
- Switched the UI theme handling to a shared class-based approach so the popup and calendar stay visually consistent.
- Added dark-mode styling coverage across the main extension UI, including:
  - popup containers and controls
  - calendar layout and headers
  - saved-course cards
  - conflict summaries

### Schedule management improvements

- Added a `Clear Calendar` action that removes all saved courses from the active schedule without deleting the schedule itself.
- The clear action now exists in:
  - the calendar page
  - the popup
- Added confirmation before clearing so the action is not triggered accidentally.

### Waitlist support

- Added a per-course waitlist state to saved courses.
- Reworked the original waitlist-note idea into a simpler toggle-based flow.
- Each saved course on the calendar sidebar can now be marked or unmarked as waitlisted.
- Waitlist status now appears directly in both places where it matters most:
  - on the saved-course card in the calendar sidebar
  - on the corresponding block in the weekly calendar grid
- Refined the calendar waitlist label styling so it is visually prominent against course colors.

### Conflict UX improvements

- Improved conflict data so overlaps now track exact overlapping windows, not just the day.
- Conflict summaries now show clearer text such as:
  - which two courses overlap
  - on which day
  - during what exact time range
- Added a conflict count indicator in the calendar header.
- Added `Conflict` badges to saved-course cards that participate in any overlap.
- Made individual conflict entries in the `Schedule Conflicts` panel clickable.
- Clicking a conflict now highlights the affected courses in both places:
  - the sidebar saved-course cards
  - the schedule blocks in the weekly calendar
- Refined the selected-conflict highlight so it remains clearly visible in both light mode and dark mode.
- Updated course blocks so clicking a course in the calendar opens the description page in a new tab instead of navigating away from the extension page.

### Shared state and storage updates

- Extended the saved course / storage model to support:
  - theme preference
  - waitlist status
- Added shared theme utilities so theme selection is applied consistently across extension entry points.
- Kept all of these changes local to the existing Chrome storage model without introducing a backend.

### Verification

- Repeatedly verified the application with:
  - `npm run typecheck`
  - `npm run build`
- Confirmed the pre-commit hook still passes with the new UI and storage changes in place.
