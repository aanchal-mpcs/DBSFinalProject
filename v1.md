# UChiSchedule v1

This file describes what is built and working in the current `v1` implementation of UChiSchedule.

## Overview

UChiSchedule is a Chrome extension for the UChicago MPCS course catalog. It helps students save courses, visualize them in a weekly calendar, detect schedule conflicts, and export their schedule as a calendar file.

The extension currently works on the MPCS catalog site:

- `https://mpcs-courses.cs.uchicago.edu/*`

## Core Functionality Built

### 1. Chrome extension foundation

- Built as a `Manifest V3` Chrome extension
- Uses `React`, `TypeScript`, `Vite`, and `Tailwind CSS`
- Includes:
  - content script
  - popup UI
  - background service worker
  - full-page calendar view

### 2. Course catalog integration

On the MPCS course catalog page, the extension injects a new `UChiSchedule` actions column into the course table.

For each course row, students can:

- add the course to their saved schedule
- remove the course from the saved schedule
- open a details popup
- open the RateMyProfessor search page for the instructor
- open the UChicago Course Feedback site
- open the course description page

### 3. Semester-level calendar access

On course listing pages with quarter headings such as `Spring 2026` or `Summer 2026`, the extension injects a:

- `See My Calendar` button

This lets the student jump directly from the catalog page to the saved weekly calendar view.

### 4. Course detail page actions

On individual course detail pages, the extension also injects the same actions directly on the page:

- `Add to Calendar`
- `RateMyProfessor`
- `Course Feedback`

This means students can save a course from either the catalog list page or the course detail page.

### 5. Saved schedule storage

The extension stores all saved schedule data in:

- `chrome.storage.local`

No backend is required.

Stored data includes:

- saved courses
- active schedule
- multiple schedule drafts

### 6. Multiple schedules

Students can:

- create multiple schedules
- switch between schedules
- delete schedules

This allows users to compare different possible class combinations, even though side-by-side comparison is not yet implemented.

### 7. Popup UI

The popup shows:

- the current active schedule
- saved courses
- quick conflict warnings
- schedule switching
- new schedule creation
- course removal
- button to open the full calendar
- button to go to `my.UChicago`

### 8. Weekly calendar view

The extension includes a full calendar page that shows saved courses laid out by:

- day of week
- start time
- end time

The calendar page supports:

- viewing all saved courses
- removing courses
- switching schedules
- creating schedules
- deleting schedules
- exporting a schedule as `.ics`
- opening `my.UChicago`

### 9. Conflict detection

The extension detects course conflicts when two classes overlap in time on the same day.

Conflict behavior currently includes:

- warnings in the popup
- warnings in the calendar sidebar
- conflict styling on the course catalog table
- conflict styling on course blocks in the calendar

Time parsing supports both:

- `5:30pm`
- `6pm`

### 10. Improved conflict visualization

Conflicting courses on the calendar are visually easier to understand because:

- conflict blocks are translucent
- overlapping classes are shown side by side instead of fully covering each other
- conflicting blocks keep a visible red outline

### 11. Click-through from calendar to course details

When a student clicks a course block in the weekly calendar, the extension opens that course’s full details page.

This makes the calendar actionable rather than just visual.

### 12. ICS export

Students can export their saved schedule as an `.ics` calendar file.

The current export behavior now supports:

- recurring weekly class events
- quarter-aware export ranges

The export is based on:

- the quarter shown on the course page, such as `Spring 2026`
- quarter boundary dates configured from the official UChicago academic calendar

Quarter date configuration is centralized in:

- [src/shared/quarterDates.ts](/Users/as/DesignBuildShip/FinalProject/src/shared/quarterDates.ts)

### 13. Quarter-aware export logic

The extension now stores quarter metadata on courses when available:

- term
- year

This is used so the exported calendar can span the full quarter instead of just one week.

If a saved course does not yet have this metadata because it was added before this feature existed, export falls back to a one-week schedule until the course is removed and added again.

### 14. Content script hardening

The content script has been made more fault-tolerant so that:

- a detail-page parsing failure does not break the course catalog page
- a catalog-page parsing failure does not crash all extension behavior on the page

## Summary of Current v1 Scope

As of now, `v1` includes:

- Chrome extension setup
- course scraping from the MPCS catalog
- injected actions on catalog pages
- injected actions on course detail pages
- popup UI
- full weekly calendar page
- conflict detection
- translucent overlap visualization
- multiple schedules
- calendar click-through to course pages
- `.ics` export
- quarter-aware recurring export
- direct access to `my.UChicago`

## What v1 Does Not Yet Include

The following are not yet built:

- university-wide support beyond the MPCS course catalog
- course-specific Course Feedback deep links
- inline professor/course review previews
- seat availability indicators
- dark mode
- side-by-side comparison of multiple schedules
- automatic live fetching of quarter dates from the academic calendar site

## Current Status

This is a working MVP with several stretch-goal features already implemented, especially:

- multiple schedules
- better conflict visualization
- clickable calendar-to-course navigation
- recurring quarter-based `.ics` export
