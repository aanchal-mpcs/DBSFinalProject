# UChiSchedule v3 Updates

## update1_2026-05-13

This update summarizes the work completed this week to harden the repository and development workflow around the extension.

### Secrets and repository policy

- Expanded `.gitignore` so local environment files are not accidentally committed:
  - `.env`
  - `.env.local`
  - `.env.*`
  - while still allowing `.env.example`
- Added a repo-local `AGENTS.md` policy file to make secret handling and agent boundaries explicit.
- The new agent policy now:
  - treats the repo as untrusted for secrets access by default
  - denies reading or editing `.env*`, `secrets/**`, key files, and token-bearing config
  - directs future variable documentation into `.env.example` instead of real local files

### CI and release gates

- Added a GitHub Actions CI workflow in `.github/workflows/ci.yml`.
- The new CI pipeline now runs:
  - dependency install with `npm ci`
  - explicit `typecheck`
  - production `build`
  - `npm audit --audit-level=moderate`
  - `gitleaks` secret scanning
  - GitHub dependency review on pull requests
- This gives the repo an actual remote enforcement path instead of relying only on local discipline.

### Local pre-commit enforcement

- Added Husky and wired it through a `prepare` script in `package.json`.
- Added a real `.husky/pre-commit` hook that now runs before commits:
  - a staged diff scan for secret-like content
  - `npm run typecheck`
  - `npm run build`
- Refined the hook so it avoids false positives from:
  - the GitHub-managed `secrets.GITHUB_TOKEN` workflow line
  - the hook script scanning its own regex rules

### Build-tool security upgrades

- Upgraded the main build toolchain to reduce known dependency risk:
  - `vite` to `^7.3.3`
  - `@vitejs/plugin-react` to `^5.2.0`
  - `postcss` to `^8.5.14`
- Added an npm override so `@crxjs/vite-plugin` uses patched `rollup@2.80.0`.
- Refreshed `package-lock.json` to capture the new dependency graph.

### Verification and outcomes

- Confirmed the local production build still succeeds after the toolchain upgrade.
- Confirmed the Husky pre-commit hook runs cleanly end to end.
- Confirmed `npm audit` reached zero reported vulnerabilities after the dependency remediation.
- Pushed the full security baseline to GitHub on `main`.
